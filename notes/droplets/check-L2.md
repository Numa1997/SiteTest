## Notes

1. (3.3)/(3.4) rest on the partner arriving with the speed of the air ("slaved"). For an overdamped partner, whether eta crosses zero depends on the arrival speed: no crossing iff eta'(0) >= k_fast eta(0), i.e. an arrival speed up to abs(k_fast) eta (>= 6 eta at St <= 1/12). The physical partner moves at 3 eta, so the criterion holds. The numerical full-axis integration confirms that St_c = 1/12 is the true threshold of the nonlinear problem, so the printed argument is sound; the text says "creeps toward the surface for ever", which is exactly the slaved case. Not an error.
2. In (3.5) b_c is the offset at infinity. The model computes E at a finite start (200 radii creeping, 30 potential) from the flux formula above, which equals b_c^2/(1+p)^2 only as Z -> oo. At Z = 200 for the realistic pair b_c^2/(1+p)^2 = 0.3401 against E_flux = 0.3375 (about 0.8 % apart), so reading b_c off a finite-Z run and squaring would be wrong by that much, but the model uses the flux form, as the text's parenthesis says.
3. "Starting at 400 radii instead changes E(40,8) by less than 1e-4." My integrator at rtol 1e-13: E_S(200) = 0.337474, E_S(400) = 0.337388 (change 8.6e-5, model 0.337474 and 0.337458: 1.6e-5), so the claim holds for E_S; weighted by 0.986 it stays below 1e-4. With a looser tolerance (rtol 1e-10) my integrator scatters by about 1.5e-4 between starts (`L2_zconv_py.out.txt`), so this claim is at the numerical noise floor of an integrator, not a derived fact.
4. "Moves Langmuir's weight, E(40,8) = 0.344, 0.358, 0.399, 0.485 for 60, 20, 6, 2": reproduced.
5. Langmuir's weight E = (E_S + E_P Re/60)/(1 + Re/60) is an interpolation, called so by the text. Not checked as physics.
