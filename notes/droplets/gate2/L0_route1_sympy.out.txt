== (1.1) swept tube, from first principles
  derived dM/dt = pi*E*W*(R + r)**2*(v_R - v_r)  ; printed: E*pi*(R+r)^2*(vR-vr)*W -> True
  units  dM/dt: kg s^-1  vs  kg s^-1  ->  OK
  M = 4pi/3 rho R^3 ; dM/dR = 4*pi*R**2*rho_w (= 4 pi rho R^2 : used by the text)
  limit W->0 : dM/dt -> 0 ; sign: positive for vR>vr (R>r), zero at R=r under Stokes

== (1.2) insert Stokes v(a)=k a^2 and dM/dt = 4 pi rho R^2 dR/dt
  difference derived - printed = 0
  units  k = 2 drho g /(9 mu)  [expected 1/(m s)]: m^-1 s^-1  vs  m^-1 s^-1  ->  OK
  units  dR/dt = E k W/rho (R+r)^3 (R-r)/R^2 /4: m s^-1  vs  m s^-1  ->  OK
  limit r<<R : lim_{r->0} dR/dt / R^2 = E*W*k/(4*rho_w)  (= E k W/(4 rho) = c)

== (1.3) separable ODE dR/dt = c R^2
  dsolve: Eq(R(t), -1/(c*t - 1/R_0))
  printed form satisfies ODE: True ; R(0)=R0: True
  blow-up time (denominator zero): [1/(R_0*c)]  printed t* = 1/(c R0)
  units  c R0 t: 1 (dimensionless)  vs  1 (dimensionless)  ->  OK
  limit W->0 (c->0): R(t) -> R_0
  t = t*(1 - R0/R): True
  40->60 um fraction of t*: 1/3  ; 40->100: 3/5
  powers of R: area R^2 * speed R^2 / (mass per dR ~ R^2) -> R^2

== (1.4) partial fractions: F'(R) must equal R^2/((R+r)^3 (R-r))
  dF/dR - integrand = 0
  independent: apart(integrand) = -r/(2*(R + r)**3) + 3/(4*(R + r)**2) - 1/(8*r*(R + r)) - 1/(8*r*(-R + r))
  sympy integrate gives: (-2*r*(3*R + 2*r) + (R**2 + 2*R*r + r**2)*log((R - r)/(R + r)))/(8*r*(R**2 + 2*R*r + r**2))
  limit r->0 of F: -1/R  (expected -1/R)
  limit R->oo of F: 0  (so blow-up time = -F(R0)*4rho/(EkW))
  r->0 : t(R) = 4*rho_w*(R - R_0)/(E*R*R_0*W*k)  ; compare (1.3) t = 4rho/(EkW)*(1/R0-1/R)
  sign: dF/dR = R^2/((R+r)^3 (R-r)) > 0 for R>r>0, so t increases with R
