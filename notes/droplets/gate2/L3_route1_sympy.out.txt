== (4.1)  kinetic energy = centre-of-mass part + relative part
  v1 = V + m2/M dv : Matrix([[0, 0, 0]])  ; v2 = V - m1/M dv : Matrix([[0, 0, 0]])  (both 0: the two decompositions printed in the text are exactly the centre-of-mass split)
  KE - [M V^2/2 + mu_red dv^2/2] = 0
  cross terms m1 V.(m2/M dv) + m2 V.(-m1/M dv) = 0
  momentum conservation: total momentum m1 v1 + m2 v2 = M V, so V is constant in any collision (internal forces); a perfect merger ends with all mass at V:
  KE before - KE after merger (energy available to deform / dissipate) = 0 (0 means it equals mu_red dv^2/2 = CKE)
  units  CKE = mu_red dv^2/2: kg m^2 s^-2  vs  kg m^2 s^-2  ->  OK
  limits: m2 -> oo (wall): mu_red -> m1 (=m1, CKE = m1 dv^2/2) ; equal masses mu_red = m1/2  (= m/2) ; dv = 0 -> CKE = 0 ; CKE >= 0 always (mu_red > 0)
  mu_red <= min(m1, m2): 4/5 (spot value 2 - 6/5 = 4/5 > 0)
