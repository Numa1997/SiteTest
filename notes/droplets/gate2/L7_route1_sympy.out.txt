== (8.1)  dN_new/dt = sum_pairs K n1 n2 F
  units  K n1 n2  [events per m3 per s]: m^-3 s^-1  vs  m^-3 s^-1  ->  OK
  units  K n1 n2 F  [new particles per m3 per s]: m^-3 s^-1  vs  m^-3 s^-1  ->  OK
  pair counting: N1 drops of kind 1 and N2 of kind 2 in a volume V: N1 N2 pairs, each meeting at rate K/V -> events per volume = K N1 N2/V^2 = K n1 n2.
  same kind: N(N-1)/2 pairs -> events per volume = K N(N-1)/(2 V^2) -> (1/2) K n^2 for large N: K/2 = K/2 (times n^2)
  so a sum over all pairs of bins (i <= j) needs the factor 1/2 for i = j: the script tools/run_cold.cjs uses rate = K n_p n_q (1/2 if i == j), as required.
  limits: F = 0 (rime splintering at -10 C) -> 0 ; F constant -> N_new = F x event rate.

== (8.2)  F = alpha A [1 - exp(-(C K0/(alpha A))^gamma)], gamma = 0.3
  units  alpha A  (surface x bumps per area): 1 (dimensionless)  vs  1 (dimensionless)  ->  OK
  units  C K0/(alpha A): 1 (dimensionless)  vs  1 (dimensionless)  ->  OK
  with y = (C K0/(alpha A))^gamma:  F = alpha A (1 - exp(-y))
  hard hit  C K0 -> oo (y -> oo): F/(alpha A) -> 1  = every bump breaks, F -> alpha A
  no energy K0 -> 0 (y -> 0): F/(alpha A) -> 0 (no energy, no fragments)
  dF/dK0 = A*alpha*gamma*(C*K_0/(A*alpha))**gamma*exp(-(C*K_0)**gamma/(A*alpha)**gamma)/K_0 ; minus alpha A e^-y gamma y/K0 : 0  (positive: F rises monotonically with the energy)
  local exponent d ln F/d ln K0 = gamma*(C*K_0/(A*alpha))**gamma/(exp((C*K_0)**gamma/(A*alpha)**gamma) - 1)  -> gamma * y e^-y/(1 - e^-y); limit y -> 0: 1  so F ~ K0^gamma
  soft hit: 1 - exp(-y) = y - y**2/2 + y**3/6 + O(y**4) -> F = alpha A [x^0.3 - x^0.6/2 + x^0.9/6 - ...] = alpha^0.7 A^0.7 (C K0)^0.3 (1 - x^0.3/2 + ...) ; relative correction x^0.3/2 at x = 1.74e-5 : 0.01867
  scaling: K0 x 10 -> F x 10^0.3 = 1.9953  ; K0 x 1e-8 -> F x 0.00398  (the weak power: eight orders of energy lower give only 2.4 orders fewer fragments)
