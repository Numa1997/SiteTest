# One calm motion for every click: state of this chat (27 November 2026)

Branch `ccr-228c349f-u7gpuw`. Reread this first after a compaction.

## Aim (Numa's task, verbatim points)
Give every click on phyeinusul.com one calm, consistent motion, modelled on the expanding table sections of the
restaurant floor-plan work. Only navigation and interface motion: folds, cards, menus, tabs, page changes, buttons, hover.
Simulations and animated backgrounds untouched. Tokens: --ease cubic-bezier(.65,0,.35,1); --dur .75s (fold open/close);
--dur-s .45s (hover, press, colour). JS motion: smootherstep t^3(t(6t-15)+10), same durations, requestAnimationFrame.
Patterns: grid-template-rows 0fr->1fr with min-height:0/overflow hidden child; content fades with opacity; arrow turns
with the same ease; items rise in on opening (opacity 0, translateY 14px, .7s, delay i*45ms+120ms), only on opening;
toggles change a class only; hover lifts 2px with a soft shadow over .45s; page changes and in-page jumps glide
(ease-out ~.7s); prefers-reduced-motion switches everything off. Test 390, 844, 1100, 1440 px, en/de/ar; screenshots
halfway through an opening. A "Motion" entry in the site guide. Merge to main and publish; commits carry no Claude author.
Delete scratch files and branches made; report what was deleted and kept.

## Decisions
- The site has two main stylesheets (site.css: home, lists, Portfolios, Lucretius; sim.css: simulation pages) and no
  single file every page loads. The tokens go in a new `styles/motion.css`, linked first on every page, so there is
  one place to change. de/ar pages regenerated by tools/i18n/build.py.
- The Portfolios study pages (portfolios/*/index.html, built by portfolios-src build_combined.py) are separate builds;
  not in scope this time.
- The home shelf of plates keeps the browser's smooth scroll: it uses scroll snapping, which fights a scripted scroll.
