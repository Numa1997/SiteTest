1. Keys. Three repository secrets (the owner creates them): R2_ACCOUNT_ID, R2_ACCESS_KEY_ID, R2_SECRET_ACCESS_KEY, an R2 API token

2. tools/sims/r2.py, the store.
   - put(local_path, key, sha256, size): first HEAD the key. If it exists with the same size and the same sha256 (kept as object
     metadata "sha256"), do nothing and report "already stored". If it exists with anything else, stop with an error: a key is
     never overwritten (the site caches every /r2/ address for a year as immutable). Otherwise upload (multipart for big files: the
     library's managed transfer is fine), with metadata sha256, then READ IT BACK: download the whole object as a stream and compute
     size and SHA-256 of what R2 now holds; any difference is an error (and the bad object is deleted, so a retry can upload again).
   - head(key) -> (size, sha256) or None.
   - Every network call is retried 3 times with backoff (2, 8, 30 s) on errors and 5xx answers; a 4xx other than 404 is not retried.
   - Usable as a module (pipeline.py imports it) and from the command line: python3 tools/sims/r2.py head <key>.

3. Run addresses. A run's address is <run> = <date>-v<version>, date = the UTC day the notebook wrote in its index, version = the
   Kaggle notebook version (for a sharded run, the version of shard 1). Objects: sims/<sim>/<run>/<file> for one shard,
   sims/<sim>/<run>/shard-<i>-of-<n>/<file> for n > 1. A same-day rerun therefore gets a new address and never touches the old one.
   The repository keeps public/data/sims/<sim>/<run>/index-<sim>.json (one combined index, see 6) and the model's small summary
   files the registry names in "repo_files" (default: none). Nothing else of a run with "store": "r2" is committed.

4. Shards, organised. A registry entry may say "shards": n (default 1). The model's run function is then called as
   run(out_dir, shard=i, shards=n) (i from 1 to n) and must compute exactly its own part of the parameter grid; a model without
   shards keeps run(out_dir). Each shard is ONE Kaggle notebook version (so each version's output stays below Kaggle's working-folder
   limit, about 20 GB), written under <out>/shard-<i>-of-<n>/ with its own index-<sim>.json that also records "shard": i,
   "shards": n and "grid_part" (whatever the model returns as its part, for example {"mass_ratio": [1, 2]}). The engine computes the
   shards one after another, and for each: push, wait, download that version only, check, upload to R2, file into the Kaggle dataset,
   delete the local copy, then the next shard. So the runner holds one shard at a time (its disk has about 30 GB free). A failed
   shard stops the run; the shards already stored stay stored and are reported in the status, and collect mode (7) can finish the run
   shard by shard. The combined index lists every file with its shard.

````python
"""The simulations pipeline: Kaggle computes, GitHub stores, Cloudflare serves. Run by .github/workflows/sims-kaggle.yml.

For one simulation (a model file tools/sims/<sim>.py with a run(out_dir) function, listed in tools/sims/registry.json) it:
  1. writes the notebook folder: kernel-metadata.json and the script tools/sims/kaggle_sims.py with JOB = <sim> and
     COMMIT = the commit being run, so Kaggle computes exactly the code in git;
  2. pushes it as a new version of the private CPU notebook numakoudsie/phyein-usul-simulations (`kaggle kernels push`);
  3. polls `kaggle kernels status` every 20 s until the run is complete (or fails, or the time limit passes);
  4. downloads the run's output (`kaggle kernels output`), finds index-<sim>.json, and checks every listed file's size and
     SHA-256 against it;
  5. copies the files to public/data/sims/<sim>/<date of generation>/ and adds the generation to public/data/sims/generations.json.
     Large data (registry "store": "release", 23 November 2026): the files matching the entry's "release_files" patterns are not
     put in the repository but attached to the GitHub release sims-<sim>-<date> (gh, with the workflow's own token), their sizes
     checked against the release afterwards; only the other files (the index, the summary with every fingerprint) are committed,
     and the generation records the release and its files. The site's Worker serves those files under /rel/<tag>/<file>.
A registry entry may also ask for the GPU ("gpu": true) and a longer wait ("timeout_s").
The workflow then puts the data on main (tools/sims/land.py); Cloudflare Workers Builds publishes the site.

Authentication: the official Kaggle tool reads the environment variable KAGGLE_API_TOKEN (a repository secret of the same name).
Kaggle's `kernels push` exits with status 0 even when Kaggle refuses the push, so its printed answer is read and checked.

Usage: python3 tools/sims/pipeline.py <sim> <commit> [--kaggle <command>] [--timeout <s>] [--gh <command>]
Exit status 0 only when every check passed; anything else stops the workflow before a commit."""
import argparse, datetime, fnmatch, hashlib, json, os, re, shutil, subprocess, sys, tempfile, time

ROOT = os.path.abspath(os.path.join(os.path.dirname(__file__), "..", ".."))
OWNER, SLUG, TITLE = "numakoudsie", "phyein-usul-simulations", "Phyein Usul simulations"
REF = f"{OWNER}/{SLUG}"

def log(*a): print(time.strftime("%H:%M:%S"), *a, flush=True)

def kaggle(cmd, args):
    r = subprocess.run(cmd + args, capture_output=True, text=True)
    out = (r.stdout or "") + (r.stderr or "")
    log("$ kaggle " + " ".join(args)); log(out.strip()[-1500:])
    return r.returncode, out

def main():
    ap = argparse.ArgumentParser(); ap.add_argument("sim"); ap.add_argument("commit")
    ap.add_argument("--kaggle", default="kaggle"); ap.add_argument("--timeout", type=int, default=None); ap.add_argument("--gh", default="gh")
    a = ap.parse_args(); K = a.kaggle.split()
    reg = json.load(open(os.path.join(ROOT, "tools/sims/registry.json")))["sims"]
    if a.sim not in reg or not os.path.exists(os.path.join(ROOT, reg[a.sim]["model"])):
        sys.exit(f"{a.sim} is not a simulation in tools/sims/registry.json (or its model file is missing)")
    sc = reg[a.sim]; gpu = bool(sc.get("gpu")); timeout = a.timeout or int(sc.get("timeout_s", 1800))
    big = lambda f: sc.get("store") == "release" and any(fnmatch.fnmatch(f, p) for p in sc.get("release_files", []))
    if not re.fullmatch(r"[0-9a-f]{40}", a.commit): sys.exit("commit must be a full 40-character hash")
    # 1. the notebook folder
    nb = tempfile.mkdtemp(prefix="nb-")
    src = open(os.path.join(ROOT, "tools/sims/kaggle_sims.py")).read()

        for f, m in large.items():
            if got.get(f) != m["bytes"]: sys.exit(f"{f}: the release holds {got.get(f)} bytes, the index says {m['bytes']}")

    g["generations"] = [q for q in g["generations"] if not (q["sim"] == a.sim and q["date"] == day)]   # one entry per simulation and day: a rerun the same day replaces it
    g["generations"].append(dict(sim=a.sim, date=day, notebook=REF, version=version, commit=a.commit,
                                 index=f"{a.sim}/{day}/index-{a.sim}.json", files={f: v for f, v in index["files"].items() if f not in large},

    log(f"stored under public/data/sims/{a.sim}/{day}/, generations.json updated")
````

tools/sims/land.py
````python
"""Step 7 of the simulations pipeline: put the new data on main without clashing with what was merged meanwhile.

Why: a Kaggle run takes minutes to hours, and other work is merged into main while it runs. On 23 November 2026 the data of the
double pendulum was computed and checked, but the save failed at "git pull --rebase": both the data commit and a merge from another
session had rewritten docs/files.md, a generated list, and git stopped at the clash (run 45254099718). Nothing was saved.

What it does instead, for the simulations named on the command line and the code commit they were computed from:
  1. keeps aside what pipeline.py wrote: each new generation's folder public/data/sims/<sim>/<date>/ and its entry in generations.json;
  2. takes the newest main as it is (git fetch, git reset --hard origin/main), so nothing merged meanwhile is touched;
  3. puts the kept folders back, adds the kept entries to main's own generations.json (an entry for the same simulation and date is
     replaced, every other entry stays), and generates docs/files.md again with tools/inventory.py instead of merging it;
  4. commits as the workflow's identity and pushes; if main moved again in between, starts over from 2 (five tries).
Usage: python3 tools/sims/land.py "<sim> [<sim> ...]" <commit>"""
import json, os, shutil, subprocess, sys, tempfile, time

ROOT = os.path.abspath(os.path.join(os.path.dirname(__file__), "..", ".."))
GEN = os.path.join(ROOT, "public/data/sims/generations.json")

def git(*a, check=True):
    r = subprocess.run(["git", *a], cwd=ROOT, capture_output=True, text=True)
    if check and r.returncode: sys.exit(f"git {' '.join(a)} failed: {r.stderr.strip()[-800:]}")
    return r

def main():
    sims, sha = sys.argv[1].split(), sys.argv[2]
    mine = [e for e in json.load(open(GEN))["generations"] if e["sim"] in sims and e["commit"] == sha]
    if not mine: print("nothing new to land"); return
    keep = tempfile.mkdtemp(prefix="land-")
    for e in mine: shutil.copytree(os.path.join(ROOT, "public/data/sims", e["sim"], e["date"]), os.path.join(keep, e["sim"], e["date"]))
    msg = f"Simulation data from Kaggle: {' '.join(sims)}(notebook numakoudsie/phyein-usul-simulations, code {sha[:7]})"
    for attempt in range(1, 6):
        git("fetch", "-q", "origin", "main"); git("reset", "-q", "--hard", "origin/main")
        g = json.load(open(GEN))
        for e in mine:
            dest = os.path.join(ROOT, "public/data/sims", e["sim"], e["date"])
            if os.path.exists(dest): shutil.rmtree(dest)
            shutil.copytree(os.path.join(keep, e["sim"], e["date"]), dest)
            g["generations"] = [q for q in g["generations"] if not (q["sim"] == e["sim"] and q["date"] == e["date"])] + [e]
        json.dump(g, open(GEN, "w"), indent=1, ensure_ascii=False); open(GEN, "a").write("\n")
        r = subprocess.run([sys.executable, "tools/inventory.py"], cwd=ROOT, capture_output=True, text=True)
        if r.returncode: sys.exit("tools/inventory.py failed: " + (r.stdout + r.stderr)[-800:])
        git("add", "public/data/sims", "docs/files.md")
        if git("diff", "--cached", "--quiet", check=False).returncode == 0: print("nothing new"); return
        git("commit", "-q", "-m", msg)
        if git("push", "origin", "HEAD:main", check=False).returncode == 0:
            print(f"landed on main (try {attempt}): {git('rev-parse', 'HEAD').stdout.strip()}"); return
        print(f"main moved during try {attempt}; starting again from the newest main"); time.sleep(10)
    sys.exit("could not land the data after five tries")

if __name__ == "__main__":
    main()
````

````python
"""Step 10 of the simulations pipeline: check the live site after a run (docs/kaggle-sims.md).

For one simulation and the code commit it was computed from:
  1. wait until https://phyeinusul.com/data/sims/generations.json lists that simulation from that commit (Cloudflare has published);
  2. download each of the simulation's files from the live site and compare size and SHA-256 with generations.json;
  3. open every live page that plays the simulation (tools/sims/registry.json) in headless Chromium and require: no page errors, the
     data file answered 200, and the page reports the file checked (sha_ok) and from that same commit.
Writes a summary to GitHub's job summary when it runs there. Exit status 0 only if all three hold.
Usage: python3 tools/sims/verify_live.py <sim> <commit> [--timeout s]"""
import argparse, hashlib, json, os, sys, time, urllib.error, urllib.request

ROOT = os.path.abspath(os.path.join(os.path.dirname(__file__), "..", ".."))
REG = json.load(open(os.path.join(ROOT, "tools/sims/registry.json")))

def log(*a): print(time.strftime("%H:%M:%S"), *a, flush=True)
def get(url):
    req = urllib.request.Request(url + ("&" if "?" in url else "?") + "nocache=%d" % time.time(), headers={"Cache-Control": "no-cache", "User-Agent": "scenes-verify"})
    with urllib.request.urlopen(req, timeout=30) as r: return r.read()

def main():
    ap = argparse.ArgumentParser(); ap.add_argument("sim"); ap.add_argument("commit"); ap.add_argument("--timeout", type=int, default=900)
    a = ap.parse_args(); site = REG["site"]; sc = REG["sims"].get(a.sim)
    if not sc: sys.exit(f"{a.sim} is not in tools/sims/registry.json")
    report = [f"### Live check: {a.sim}", ""]
    # 1. published?
    t0 = time.time(); e = None
    while time.time() - t0 < a.timeout:
        try:
            g = json.loads(get(site + "/data/sims/generations.json"))
            e = next((q for q in reversed(g["generations"]) if q["sim"] == a.sim and q["commit"] == a.commit), None)
        except Exception as ex: log("not yet:", ex)
        if e: break
        time.sleep(15)
    if not e: sys.exit(f"after {a.timeout} s the live generations.json still has no {a.sim} from {a.commit[:7]}")
    log(f"published after {round(time.time()-t0)} s: {e['date']}, Kaggle version {e['version']}"); report.append(f"- published on {site} after {round(time.time()-t0)} s ({e['date']}, Kaggle notebook version {e['version']})")
    # 2. files
    for f in sc["files"]:
        b = get(f"{site}/data/sims/{a.sim}/{e['date']}/{f}"); h = hashlib.sha256(b).hexdigest()
        if len(b) != e["files"][f]["bytes"] or h != e["files"][f]["sha256"]: sys.exit(f"live {f} differs from generations.json")
        log(f"{f}: {len(b)} bytes, SHA-256 matches"); report.append(f"- `{f}`: {len(b)} bytes, SHA-256 `{h[:12]}…` matches")
    # 2b. large data: every release file must answer through the site's Worker (/rel/<tag>/<file>), a byte range must come back as
    #     asked, and the total size must be the one in generations.json
    for f, meta in (e.get("release_files") or {}).items():
        req = urllib.request.Request(f"{site}/rel/{e['release']}/{f}", headers={"Range": "bytes=0-1023", "User-Agent": "scenes-verify"})
        part, cr, why = b"", "", ""
        for attempt in range(3):   # one failed answer is named and tried again; three in a row fail the check
            try:
                with urllib.request.urlopen(req, timeout=60) as r: part, cr = r.read(), r.headers.get("Content-Range", "")
                break
            except urllib.error.HTTPError as ex:
                why = f"HTTP {ex.code}, upstream {ex.headers.get('x-upstream-status', 'not given')}"; log(f"{f}: try {attempt + 1} failed ({why})"); report.append(f"- `{f}`: try {attempt + 1} failed ({why})"); time.sleep(5)
        if len(part) != min(1024, meta["bytes"]) or not cr.endswith("/%d" % meta["bytes"]): sys.exit(f"live /rel/{e['release']}/{f}: got {len(part)} bytes, Content-Range '{cr}', expected a total of {meta['bytes']} ({why})")
        log(f"{f}: served from the release through /rel/, {meta['bytes']} bytes"); report.append(f"- `{f}`: served from release `{e['release']}` through `/rel/`, {meta['bytes']} bytes, ranges work")
    # 3. pages
    from playwright.sync_api import sync_playwright
    exe = os.environ.get("CHROMIUM") or None
    with sync_playwright() as p:
        br = p.chromium.launch(executable_path=exe, args=["--no-sandbox"])
        for pgdef in sc["pages"]:
            pg = br.new_page(viewport={"width": pgdef["width"], "height": pgdef["height"]}); errs, got = [], {}
            pg.on("pageerror", lambda x: errs.append(str(x)))
            pg.on("response", lambda r: got.__setitem__(r.url.split("?")[0].split("/")[-1], r.status) if "/data/sims/" in r.url else None)
            pg.goto(site + pgdef["path"] + "?verify=%d" % time.time(), wait_until="load"); pg.evaluate(f"window.scrollTo(0,{pgdef.get('scroll',0)})")
            st = {}
            for _ in range(40):
                pg.wait_for_timeout(500); st = pg.evaluate(pgdef["probe"])
                if not st.get("waiting"): break
            br_ok = not errs and all(got.get(f) == 200 for f in sc["files"]) and st.get("sha_ok") is True and st.get("commit") == a.commit
            log(pgdef["path"], "errors", errs, "files", got, "page", st)
            report.append(f"- page `{pgdef['path']}` at {pgdef['width']} px: {'plays it' if br_ok else 'FAILED'} ({json.dumps(st)}; page errors: {len(errs)})")
            if not br_ok:
                if os.environ.get("GITHUB_STEP_SUMMARY"): open(os.environ["GITHUB_STEP_SUMMARY"], "a").write("\n".join(report) + "\n")
                sys.exit(f"page {pgdef['path']} does not play {a.sim} from {a.commit[:7]}")
        br.close()
    report.append(""); report.append("All checks passed: Kaggle → GitHub → Cloudflare → page.")
    if os.environ.get("GITHUB_STEP_SUMMARY"): open(os.environ["GITHUB_STEP_SUMMARY"], "a").write("\n".join(report) + "\n")
    log("all checks passed")

if __name__ == "__main__":
    main()
````

````python
def file_dataset(sim, version, src, K=("kaggle",)):
    K = list(K)
    idx = [os.path.join(d, f) for d, _, fs in os.walk(src) for f in fs if f == f"index-{sim}.json"]
    if len(idx) != 1: sys.exit(f"expected one index-{sim}.json under {src}, found {len(idx)}")
    index = json.load(open(idx[0])); here = os.path.dirname(idx[0])
    # the figure's own dataset (docs/kaggle-pipeline.md: one private dataset per figure, numakoudsie/fig<N>-<topic>), named in the
    # registry entry as "dataset" and "dataset_title"; a simulation without a figure gets numakoudsie/phyein-usul-<sim>
    reg = json.load(open(os.path.join(ROOT, "tools/sims/registry.json")))["sims"].get(sim, {})
    ref = reg.get("dataset") or "numakoudsie/phyein-usul-" + re.sub(r"[^a-z0-9]+", "-", sim.lower()).strip("-")
    title = reg.get("dataset_title") or f"Phyein Usul simulation data: {sim}"
    # Layout of docs/kaggle-pipeline.md: <notebook>/v<version>/output/ plus manifest.json. The Kaggle tool packs each top-level folder
    # of the upload into one archive of that folder's contents and Kaggle unpacks it at the dataset's root, so the tree is wrapped
    # in one more folder ("upload") to arrive as phyein-usul-simulations/v<version>/... (seen 23 November 2026: an unwrapped folder
    # arrived flat at the root).
    stage = tempfile.mkdtemp(prefix="ds-"); wrap = os.path.join(stage, "upload")
    folder = f"{NOTEBOOK.split('/')[1]}/v{version}"; dst = os.path.join(wrap, folder, "output"); os.makedirs(dst)
    def put(p, q):
        os.makedirs(os.path.dirname(q), exist_ok=True)
        os.link(p, q) if os.stat(p).st_dev == os.stat(stage).st_dev else shutil.copy2(p, q)
    manifest = {}
    for f, meta in sorted(index["files"].items()):
        p = os.path.join(here, f); h = hashlib.sha256()
        with open(p, "rb") as fh:
            for chunk in iter(lambda: fh.read(1 << 24), b""): h.update(chunk)
        if os.path.getsize(p) != meta["bytes"] or h.hexdigest() != meta["sha256"]: sys.exit(f"{f}: size or SHA-256 differs from the index")
        put(p, os.path.join(dst, f)); manifest[f] = meta
    shutil.copy2(idx[0], os.path.join(dst, f"index-{sim}.json"))
    for f in os.listdir(src):   # the run's log, as Kaggle hands it out with the output
        if f.endswith(".log"): shutil.copy2(os.path.join(src, f), os.path.join(wrap, folder, f))
    folders = {folder: dict(sim=sim, date=index.get("date"), commit=index["source"]["commit"], files=manifest)}
    json.dump(dict(notebook=NOTEBOOK, version=version, sim=sim, date=index.get("date"), commit=index["source"]["commit"],
                   code=f"https://github.com/Numa1997/SiteTest/tree/{index['source']['commit']}/tools/sims", files=manifest),
              open(os.path.join(wrap, folder, "manifest.json"), "w"), indent=1)
    total = sum(m["bytes"] for m in manifest.values())
    log(f"{len(manifest)} files, {total} bytes checked against the index; staged as {folder}/output/")
    def ver():   # the dataset's newest version number, or None if it does not exist
        o = kaggle(K, ["datasets", "status", ref, "--format", "json"], check=False)
        m = re.search(r'"current_version_number"\s*:\s*(\d+)', o); return int(m.group(1)) if m else None
    before = ver(); exists = before is not None
    if exists:
        # A Kaggle dataset version holds only what is uploaded with it. The rule is that the dataset holds every run of the figure,
        # so the runs already in it are downloaded and uploaded again beside the new one. Files outside <notebook>/ (the flat layout
        # of the first filing, 23 November 2026) are left out; they stay in the older dataset versions.
        old = tempfile.mkdtemp(prefix="old-"); kaggle(K, ["datasets", "download", ref, "-p", old, "--unzip"])
        base = os.path.join(old, NOTEBOOK.split("/")[1]); kept = 0
        if os.path.isdir(base):
            for d, _, fs in os.walk(base):
                for f in fs:
                    rel = os.path.relpath(os.path.join(d, f), old)
                    if rel.startswith(folder + "/"): continue   # the same version filed again: the new copy wins
                    put(os.path.join(d, f), os.path.join(wrap, rel)); kept += 1
                    if f == "manifest.json": folders[os.path.dirname(rel)] = json.load(open(os.path.join(d, f)))
        log(f"{kept} files of earlier runs kept beside the new one")
        write_meta(stage, reg, sim, ref, title, folders)
        out = kaggle(K, ["datasets", "version", "-p", stage, "-r", "tar", "-m", f"{NOTEBOOK} version {version}, code {index['source']['commit'][:7]}"])
        if "being created" not in out: sys.exit("Kaggle did not accept the dataset version (its answer is above)")
    else:
        write_meta(stage, reg, sim, ref, title, folders)
        out = kaggle(K, ["datasets", "create", "-p", stage, "-r", "tar"])
        if "being created" not in out: sys.exit("Kaggle did not accept the new dataset (its answer is above)")
    # Wait for THIS version. "ready" alone is not enough: while Kaggle unpacks a new version, the status still reports the previous
    # version as ready (23 November 2026: a 7 GB version was reported ready after 30 s and was not yet there). So wait until the
    # version number has risen and that version is ready.
    t0 = time.time(); state = ""
    while time.time() - t0 < 3 * 3600:   # Kaggle unpacks and indexes the upload; large data takes many minutes
        time.sleep(float(os.environ.get("POLL_S", 60)))
        state = kaggle(K, ["datasets", "status", ref], check=False).strip().lower()
        if "error" in state or "failed" in state: sys.exit(f"Kaggle reports the dataset as: {state}")
        v = ver()
        if "ready" in state and v is not None and (before is None or v > before): break
        log(f"newest version {v} (before the upload: {before}), state {state}: waiting")
    else:
        sys.exit(f"the new dataset version was not there within 3 hours (last state: {state})")
    # "datasets version" does not change the subtitle and description; set them from the same file
    update_card(K, ref, stage)
    shutil.rmtree(stage)
    log(f"dataset {ref} version {v} ready with {folder}/ ({total} bytes) after {round(time.time() - t0)} s")
    return ref, folder, total

def record(sim, version, ref, folder, total):
    g = json.load(open(GEN)); hit = [e for e in g["generations"] if e["sim"] == sim and e.get("version") == version]
    if not hit: sys.exit(f"generations.json has no {sim} from notebook version {version}")
    for e in hit:
        e["dataset"] = ref; e["dataset_path"] = folder + "/"
        e["dataset_note"] = f"the whole Kaggle output of {NOTEBOOK} version {version}, {total} bytes, filed as one version of this dataset"
    json.dump(g, open(GEN, "w"), indent=1, ensure_ascii=False); open(GEN, "a").write("\n")
    return hit[-1]["commit"]
````
