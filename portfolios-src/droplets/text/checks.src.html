How the numbers are tested

Checks

The model is one block of JavaScript that runs in this page and in Node. Three kinds of test stand behind every number in the notes: exact solutions the model must reproduce, independent recomputations in Python (constants typed again, integrations by SciPy, derivations by SymPy), and a script that recomputes every number quoted in the notes and finds it in the text.
