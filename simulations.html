    Every simulation, the same four parts

    Open any figure and you find the same layout, so what you learn on one page carries over to the next.

    1. 01 · Figure

      Change it and watch

      Sliders and clicks set the physics: lengths, frequencies, masses, start conditions, the wind. The picture answers at once, or, where the whole run is solved first, as soon as you press Solve.

    2. 02 · Lecture note

      The physics, written out

      A motivating picture, the model, the derivation, the numerical method, what is on screen and what the model leaves out, with numbered equations, figures and exercises.

    3. 03 · From symbols to code

      The walkthrough

      Each formula next to the line of the page’s own code that computes it, with the live value beside it.

    4. 04 · Data panel

      The numbers

      Every variable the figure draws, with units. Pin a point with Read values, record one round as a table, check a value three ways, save it as .npz or CSV.
