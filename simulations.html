    Open any figure and you find the same layout, so what you learn on one page carries over to the next.

      Sliders and clicks set the physics: lengths, frequencies, masses, start conditions. The picture answers at once.

      The derivation

      Six steps: the physical picture, the model, the derivation, the numerical method, what is on screen, and what the model leaves out.

    4. 04 · Data panel

      The numbers

      Every variable the figure draws, with units. Pin a point with Read values, record one round as a table, check a value three ways, save it as .npz or CSV.
