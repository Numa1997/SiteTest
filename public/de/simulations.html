Interaktive Physik · Simulationen und Skripte

Simulationen.

Jede Abbildung ist ein kleines Labor mit seinem Skript darunter: das physikalische Bild, das Modell, die Herleitung, das numerische Verfahren und jede Zahl, aus der das Bild gezeichnet wird.

Jede Simulation, dieselben vier Teile

Jede Abbildung ist gleich aufgebaut; was Sie auf einer Seite lernen, gilt auch auf der nächsten.

  1. 01 · Abbildung

    Ändern und zusehen

    Schieberegler und Klicks stellen die Physik ein: Längen, Frequenzen, Massen, Anfangsbedingungen, den Wind. Das Bild antwortet sofort oder, wo der ganze Lauf vorab gelöst wird, sobald Sie auf Lösen drücken.

  2. 02 · Skript

    Die Physik, ausgeschrieben

    Ein motivierendes Bild, das Modell, die Herleitung, das numerische Verfahren, was auf dem Bildschirm zu sehen ist und was das Modell weglässt, mit nummerierten Gleichungen, Abbildungen und Aufgaben.

  3. 03 · Von den Symbolen zum Code

    Der Rundgang

    Jede Formel neben der Zeile im Code der Seite, die sie berechnet, mit dem aktuellen Wert daneben.

  4. 04 · Datenpanel

    Die Zahlen

    Jede Variable, die die Abbildung zeichnet, mit Einheiten. Mit „Werte ablesen“ einen Punkt festhalten, eine Runde als Tabelle aufzeichnen, einen Wert auf drei Wegen prüfen, als .npz oder CSV speichern.
